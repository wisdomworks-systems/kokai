# kokai

株式会社ウィズダムワークスの社内システム（WorksBoard）から使う、小さな公開ページです。

## cal-token.html

社内システムの画面が、**利用者本人の Google カレンダーを読む**ための許可を受け取ります。

- ボタンを押した**本人の通行証だけ**を扱います
- 求める権限は **カレンダーの閲覧（`calendar.readonly`）のみ**です
- **書き込みは一切行いません**
- 受け取った通行証は、**呼び出し元の画面にだけ**渡します
- このページは**何も保存しません**

Google 側の設定は「内部」で、当社の Google Workspace の利用者以外はログインできません。

## なぜ公開しているか

Google の標準のログインは、**住所の変わらないページ**からしか呼べません。
社内システムの画面は住所が毎回変わるため、この1枚だけを分けて置いています。

このページに鍵や個人情報は含まれていません。
